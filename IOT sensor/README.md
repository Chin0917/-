# 物聯網心跳監測系統

> **基於 ThingSpeak 雲端平台之雙裝置心跳監測系統**

本專案利用 **BM53A367A 微控制器、XD-58C 心跳感測器、BMC81M001 WiFi 模組與 ThingSpeak**，建立一套具備心跳量測、雲端傳輸與遠端警示功能的 IoT 系統。

##  簡易流程

```text
使用者
  │
  ▼
XD-58C 心跳感測器
  │
  ▼
A 裝置
BM53A367A
  │
  │ WiFi / MQTT
  ▼
ThingSpeak
雲端平台
  │
  │ MQTT
  ▼
B 裝置
BM53A367A
  │
  ├─ OLED 顯示 BPM
  └─ LED 異常警示
```

##  核心技術

- **BM53A367A**：感測資料擷取與系統控制
- **XD-58C**：取得心跳脈搏類比訊號
- **BMC81M001 WiFi**：建立無線網路連線
- **MQTT**：進行 IoT 裝置與雲端間的資料傳輸
- **ThingSpeak**：儲存與交換心跳資料
- **OLED**：顯示即時 BPM
- **LED**：異常心跳警示
- **Peak Detection / Threshold**：判斷心跳訊號並計算 BPM

##  問題解決

- WiFi 模組接線錯誤造成的 `WiFi FAIL`
- RX / TX 與 SDA / SCL 腳位衝突問題
- XD-58C 感測器受到環境雜訊造成的誤判
- BPM 持續為 0 的心跳偵測問題
- 心跳計算時間與即時性的平衡
- MQTT 與 ThingSpeak 雲端資料傳輸問題

##  系統功能

-  即時取得心跳訊號
-  計算並顯示 BPM
-  上傳心跳資料至 ThingSpeak
-  OLED 遠端顯示心跳數值
-  BPM 超過設定範圍時啟動 LED 警示
-  透過 MQTT 完成雙裝置資料傳輸

##  實作成果

本專案成功完成從 **感測器 → 微控制器 → WiFi → ThingSpeak → 遠端裝置** 的完整 IoT 資料流程。

實作過程也發現 XD-58C 容易受到手部移動、環境光源與電源雜訊影響，因此透過取樣平均、Threshold 與固定時間窗口等方式改善心跳判斷結果。
